# 🖥️ Help Desk em Python

Sistema de Help Desk desenvolvido em Python para gerenciamento de chamados de suporte técnico.

## 📌 Sobre o projeto

Este projeto está sendo desenvolvido com o objetivo de praticar programação em Python e criar uma aplicação que simule um sistema de atendimento de chamados de TI.

## 🚀 Funcionalidades

- [x] Menu inicial
- [ ] Abertura de chamados
- [ ] Consulta de chamados
- [ ] Alteração de status
- [ ] Encerramento de chamados
- [ ] Cadastro de usuários
- [ ] Banco de dados
- [ ] Interface web
